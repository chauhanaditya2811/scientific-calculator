# Scientific Calculator

A modern, responsive scientific calculator built with React and Vite.

## Features

- Basic arithmetic operations
- Scientific functions: trigonometry, logarithms, roots, powers, factorials
- Degree / radian mode
- Keyboard input
- Calculation history
- LocalStorage persistence
- Responsive glass-style UI

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Tech stack

- React
- Vite
- JavaScript
- mathjs
- CSS

No backend or database is required. Calculation history is stored locally in the browser.
